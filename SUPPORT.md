# Soporte

| Necesidad | Canal recomendado |
| --- | --- |
| Defecto, tarea o propuesta trazable | Issue y GitHub Projects. |
| Cambio de código o documentación | Pull Request con revisión. |
| Decisión, evidencia, riesgo o aprendizaje del proyecto | Project Passport. |
| Arquitectura, calidad, testing, seguridad o bloqueo técnico | Revisión con Tech Lead académico. |

Los asuntos privados, evaluativos sensibles o situaciones personales no deben exponerse en Issues, Pull Requests ni Project Passport público. Deben atenderse mediante los canales académicos institucionales pertinentes.
