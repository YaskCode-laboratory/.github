# Seguridad

## Política educativa

No subas secretos, credenciales, tokens ni datos personales a repositorios, Issues, Pull Requests o documentación. Usa datos mínimos, autorizados y protegidos; revisa dependencias y corrige hallazgos antes de compartir material.

Las vulnerabilidades o exposiciones se reportan de forma responsable al equipo docente o mediante el canal institucional adecuado; no se publican detalles explotables en Issues abiertos. En sistemas con IA se consideran privacidad, riesgos, sesgos, trazabilidad de fuentes y supervisión humana. La seguridad es parte del aprendizaje y del proceso, no una verificación final.
