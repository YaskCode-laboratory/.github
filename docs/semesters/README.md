# Semestres de YaskCode Laboratory

Este índice conserva la memoria institucional de cada período académico sin exponer información privada de estudiantes, equipos o repositorios en evaluación.

## Estados

- **En preparación:** período planificado, aún sin desarrollo activo.
- **En desarrollo:** proyectos y sprints en curso.
- **En evaluación:** entregas finalizadas en proceso de revisión académica y técnica.
- **Cerrado:** período concluido, con memoria institucional consolidada.
- **Archivo publicado:** existen recursos seleccionados, autorizados y preparados para educación abierta.
