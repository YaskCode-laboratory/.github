## Enfoque tecnológico

La cohorte trabaja, según el alcance de cada proyecto, con Ingeniería del Conocimiento, RAG, recuperación semántica, embeddings, bases de datos vectoriales, evaluación del retrieval, generación de respuestas, trazabilidad, testing, documentación, GitHub Projects y GitHub Actions cuando corresponda.

## Proceso

El seguimiento integra el flujo **Backlog → Ready → In Progress → Review → Done** con la secuencia **Sprint 1 → Sprint 2 → Sprint 3 → Proyecto Final**. Las evidencias se articulan con el Marco de Ingeniería YaskCode: **Diseñar → Construir → Verificar → Compartir**.

## Organización

La cohorte se organiza en 6 equipos con trabajo colaborativo mediante Issues, Pull Requests y GitHub Projects. El seguimiento incorpora revisión técnica, acompañamiento del **Tech Lead académico** y actualización proporcional del Project Passport.

## Estado de publicación

### Proyectos públicos

> Los proyectos de esta cohorte permanecen en desarrollo y evaluación. Los proyectos seleccionados para educación abierta se incorporarán posteriormente, una vez completados los procesos de revisión técnica, autoría, consentimiento, licencia y preparación para publicación.
