# Project Passport · Especificación V1

El **Project Passport** es la bitácora estructurada que acompaña al proyecto durante todo el semestre. Registra el contexto que permite entender qué se construyó, por qué se decidió, cómo se verificó y bajo qué condiciones podría compartirse.

## Relación con el Marco de Ingeniería YaskCode

| Momento | Evidencias del Passport |
| --- | --- |
| Diseñar | Propósito, contexto, requisitos, arquitectura, ADR y riesgos. |
| Construir | Backlog, avances, decisiones, contribuciones y evidencias. |
| Verificar | Pruebas, métricas, seguridad, revisión y resultados. |
| Compartir | Fuentes, uso de IA, autoría, aprendizajes y condiciones de publicación. |

Se actualiza junto al flujo **Backlog → Ready → In Progress → Review → Done**. No reemplaza el repositorio ni GitHub Projects: conecta sus evidencias con el aprendizaje y la evaluación.

## Contenido

Según corresponda, documenta propósito, contexto, requisitos, decisiones, arquitectura, ADR, riesgos, seguridad, pruebas, métricas, resultados, evidencias, retrospectivas, fuentes, uso de IA, autoría, aprendizajes y condiciones para publicación. Debe ser breve, verificable y proporcional al proyecto.
