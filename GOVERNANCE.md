# Gobernanza de YaskCode Laboratory

## Roles

| Rol | Responsabilidad |
| --- | --- |
| Dirección académica | Define propósito formativo, criterios de evaluación y orientación del laboratorio. |
| Tech Lead académico | Traduce el marco a práctica: acompaña planificación, arquitectura, decisiones técnicas, revisión, calidad, testing, seguridad y evolución del producto. |
| Estudiantes / desarrolladores | Construyen, documentan, verifican y comunican su trabajo con responsabilidad compartida. |
| Equipos de proyecto | Gestionan el backlog, coordinan contribuciones, mantienen evidencias y actualizan el Project Passport. |

## Decisiones y seguimiento

Las decisiones se toman con evidencia proporcional al impacto. El equipo propone; el Tech Lead académico revisa decisiones técnicas relevantes; la dirección académica resuelve criterios formativos y de evaluación. El seguimiento usa sprints, GitHub Projects, Issues, Pull Requests y Project Passport.

## Revisión, cierre y apertura

Una entrega se cierra cuando cumple criterios de aceptación, documentación y evidencias acordadas, con revisión técnica cuando corresponda. La evaluación considera producto y proceso. Los proyectos siguen privados durante el semestre; una apertura posterior exige evaluación concluida, revisión, consentimiento, preparación del material y condiciones explícitas de publicación.
