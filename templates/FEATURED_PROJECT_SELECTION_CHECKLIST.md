# Checklist de selección de Featured Projects

> Checklist cualitativo; no asigna puntos ni calcula puntuaciones.

## Elegibilidad

- [ ] Evaluación académica finalizada.
- [ ] Revisión técnica realizada.
- [ ] Repositorio preparado para publicación.
- [ ] Autoría revisada.
- [ ] Consentimiento confirmado cuando corresponde.
- [ ] Licencia definida.
- [ ] Información sensible revisada.
- [ ] Publication Readiness completado.

## Valor de ingeniería

- [ ] Existe una solución técnicamente comprensible.
- [ ] Las decisiones principales pueden explicarse.
- [ ] Existe evidencia de implementación y verificación.

## Valor educativo

- [ ] El proyecto ofrece aprendizajes reutilizables.
- [ ] El contexto está suficientemente documentado.
- [ ] Otra cohorte podría comprender qué se hizo y por qué.

## Trazabilidad

- [ ] Project Passport disponible o preparado.
- [ ] Evidencias relevantes identificadas.
- [ ] Fuentes y decisiones documentadas cuando corresponde.

## Presentación pública

- [ ] README comprensible.
- [ ] Enlaces públicos funcionan.
- [ ] No existen secretos ni datos privados.
- [ ] El proyecto puede compartirse responsablemente.
