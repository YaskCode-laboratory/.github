# Checklist de preparación para publicación

- [ ] Evaluación y revisión técnica concluidas.
- [ ] Sin secretos, datos personales ni material restringido.
- [ ] Autoría, contribuciones y fuentes reconocidas.
- [ ] Uso de IA declarado cuando corresponda.
- [ ] Consentimiento y licencia revisados.
- [ ] README y contexto académico preparados.
