# Definition of Done

Una tarea o incremento puede considerarse terminado cuando, según corresponda:

- la implementación está completada;
- los criterios de aceptación están satisfechos;
- los tests se ejecutaron;
- CI es correcto cuando existe;
- la revisión técnica se realizó;
- seguridad fue considerada;
- la documentación está actualizada;
- existen evidencias disponibles;
- el Project Passport se actualizó cuando la decisión es significativa;
- el Pull Request fue revisado;
- las conversaciones relevantes están resueltas;
- el cambio está integrado correctamente.

**Done no significa únicamente “el código funciona en mi equipo”.** Debe existir evidencia proporcional al tipo y riesgo del cambio.
