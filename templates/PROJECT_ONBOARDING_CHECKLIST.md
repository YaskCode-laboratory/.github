# Checklist de onboarding de proyecto

> Lista inicial reutilizable. No requiere nombres, calificaciones ni información personal.

## Identidad

- [ ] Nombre del proyecto definido.
- [ ] Período, asignatura y nivel académico registrados.
- [ ] Modalidad individual o equipo indicada.
- [ ] Objetivo general comprendido.

## Repositorio

- [ ] README inicial creado.
- [ ] `.gitignore` apropiado configurado.
- [ ] Ausencia de secretos y credenciales verificada.
- [ ] Estructura inicial definida.
- [ ] Rama principal identificada.
- [ ] Reglas de protección aplicables revisadas.

## Ingeniería

- [ ] Problema comprendido.
- [ ] Requisitos iniciales identificados.
- [ ] Arquitectura o enfoque inicial descrito.
- [ ] Riesgos principales identificados.
- [ ] Tecnologías justificadas.

## Gestión

- [ ] GitHub Project o mecanismo de seguimiento definido.
- [ ] Backlog inicial preparado.
- [ ] Issues creados.
- [ ] Primer Sprint preparado.

## Calidad

- [ ] Estrategia inicial de testing definida.
- [ ] CI seleccionado cuando corresponde.
- [ ] Criterios de aceptación definidos.
- [ ] [Definition of Ready](DEFINITION_OF_READY.md) revisada.
- [ ] [Definition of Done](DEFINITION_OF_DONE.md) revisada.

## Trazabilidad

- [ ] Project Passport creado.
- [ ] Fuentes iniciales registradas.
- [ ] Uso de IA declarado cuando corresponde.
